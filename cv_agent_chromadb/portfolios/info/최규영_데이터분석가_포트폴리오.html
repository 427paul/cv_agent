03 — 프로젝트

프로젝트 2건

비즈니스 문제를 데이터로 정의하고, 지표 설계 → 탐색적 분석 → 시각화 → 인사이트 → 실행안으로 연결한 프로젝트를 중심으로 정리했습니다.

핵심 인사이트

2014년 4분기 모바일 매출 비중은 13.28%로 나타났습니다. AARR 분석에서 주요 개선 영역은 신규 유입(Acquisition)과 구매 전환(Activation)으로 좁히고, Retention과 객단가는 유지 대상으로 구분했습니다.

분석 과정 전체 보기접기
1

문제 정의: 모바일 매출 비중의 정체

Kaggle Toy Store E-Commerce 데이터를 바탕으로 디바이스별 매출을 비교했습니다. 2014년 4분기 Desktop 매출은 $326,854.56, Mobile 매출은 $50,037.42였으며, 모바일 매출 비중은 13.28%였습니다.

  • 분기별 총매출과 모바일 매출 비중을 함께 살펴 모바일 채널의 구조적 격차를 확인
  • 외부 E-Commerce 벤치마크를 참고해 모바일 매출 비중 25%를 목표 시나리오로 설정
2

  • GCS에 원천 데이터를 저장하고 BigQuery에 적재해 분석 환경 구성
  • Acquisition·Activation·Retention·Revenue 관점으로 지표를 구성해 디바이스별 비교가 가능하도록 분석 마트 설계
3

AARR 퍼널로 원인 분해

  • Acquisition: 모바일 신규 세션은 데스크톱의 약 40.1% 수준으로 유입 격차 확인
  • Activation: 모바일 구매 전환은 데스크톱 대비 약 35.6% 수준으로, 유입 이후 구매 과정의 이탈 개선 필요성 확인
  • Retention·Revenue: 재방문과 객단가는 상대적으로 양호한 것으로 분석해 우선 개선 영역에서 제외
4

Data Studio 대시보드 및 개선안

  • 분기별 총매출·모바일 매출 점유율과 디바이스별 AARR 지표를 시각화
  • 모바일 유입 확대와 상품 탐색·상세 진입·구매 전환 과정 개선을 핵심 과제로 제안
  • 모바일 상품 목록의 썸네일 개선 및 상세 이동 CTA 가시성 강화를 후속 실험 가설로 제시
최종 제안

Retention과 객단가를 무리하게 바꾸기보다, 모바일 유입(Acquisition)과 구매 전환(Activation)에 개선 자원을 집중하고 대시보드로 변화를 추적하는 방안을 제안했습니다.

핵심 인사이트

전체 평균에서 우수해 보였던 B 소재도 신규 타겟에서는 전환율이 낮게 나타나는 차이를 확인했습니다. B 소재 전면 확대 대신 리타겟팅·관심사 타겟에는 B, 신규 타겟에는 A를 유지하는 이원화 전략을 제안했습니다.

분석 과정 전체 보기접기
1

문제 정의: 클릭 성과가 예산 확대의 충분한 근거인가?

D2C 라이프스타일 브랜드의 Meta 광고 A/B 테스트에서 신규 소재 B가 CTR·Engagement 등 상단 지표에서 우수해 보였지만, 이 결과만으로 예산을 확대하면 실제 전환 성과를 놓칠 수 있다고 판단했습니다.

  • 분석 목적을 단순 소재 비교가 아닌 예산 확대 판단의 타당성 검증으로 정의
  • CTR과 Engagement 외에 CVR, CPA, ROAS를 함께 확인하도록 분석 기준을 설계
2

  • 전체 평균만으로 결론 내리지 않기, 데이터에 없는 사실을 만들지 않기, 모든 결론에 근거 포함하기, 비즈니스 Action으로 연결하기를 Instruction에 명시
3

세그먼트·퍼널 분석으로 평균의 함정 확인

  • 전체 평균뿐 아니라 신규 타겟, 리타겟팅, 관심사 타겟으로 나누어 소재별 성과를 비교
  • 전체 평균상 우수했던 소재가 신규 타겟에서는 오히려 전환율이 낮다는 인사이트를 도출해, 타겟별 소재 이원화 전략과 후속 A/B 테스트 제안
  • 전체 성과, 타겟별 비교, 퍼널 분석을 HTML 대시보드로 구성해 마케팅팀이 결과를 확인할 수 있도록 정리
최종 제안

전체 평균만 보고 B 소재를 전면 확대하기보다, 타겟별 전환 성과를 기준으로 예산과 소재를 차등 운영하고 후속 실험으로 개선 효과를 검증합니다.
